2b. SIP 入站测试 call.incoming ← call.bridge llm.chat

内核 SIP 入站始终只广播 call.incoming，不在服务端写死 notify / bridge / llm。 下方下拉框是客户端编排策略，随时可切换：AI 接待（llm）→ 接不住再转人工（bridge / notify 手动 Bridge）。
SIP_LISTEN_ADDR=0.0.0.0:5060 SIP_TRUNK_DID=+86... SIP_INBOUND_MODE=notify # 可选，hello 首次默认下拉；不锁死行为 SIP_KERNEL_AUTO_LLM=false # 建议 false，编排交给 Explorer / 业务 Agent LLM_PROVIDER=... LLM_API_KEY=... # llm 模式需要 # 安全组：UDP 5060 + UDP 16384–32767
SIP: — sip leg: — 状态: idle
bridge: idle
bridge 只需这一个按钮（内部等同 Card 2 的 Start call + call.bridge）。无需再点 Card 2。 请确认 Card 1 已 Connect，且页面从 http://localhost:8080 打开（允许麦克风）。
notify 不会自动听/回。顺序：Connect → 再拨打 DID → 点「AI 接待」或「转人工」；两者可来回切换（坐席 ↔ AI）。
